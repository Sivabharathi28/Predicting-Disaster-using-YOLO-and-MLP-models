# Flood Detection Using YOLO

## Overview
This project detects flood-affected areas using deep learning and YOLO models.

## Features
- Flood detection using AI
- Image prediction
- Real-time analysis
- Deep learning based classification

## Technologies Used
- Python
- YOLO
- OpenCV
- Flask
- TensorFlow

## Project Structure

```bash
app.py
train.py
predict.py
templates/
static/
```

## Dataset
Dataset collected from Roboflow.
